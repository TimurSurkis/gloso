# Gloso: обзор backend

Статус: обзор согласованных требований. История и ссылки D-* — в [реестре](decision-backend.md). Технические спецификации имеют статус проекта.

## Назначение

Backend выполняет проверяемые действия голосового ассистента для автосервисов: создаёт новые визиты либо передаёт новые заявки сотруднику. Он не передаёт аудиопоток и не служит CRM или архивом разговоров.

## Первый релиз

| Область | Согласовано |
| --- | --- |
| Режим | Calendar или Relay по выбору автосервиса |
| Calendar | Один отдельный Google Calendar на автосервис, подключение вручную через Service Account |
| Вместимость | Один визит за раз; учитывать полную длительность услуги |
| Услуги | Отдельная длительность каждой услуги автосервиса; в тестах одинаковые значения |
| Комплекс | Автоматически только настроенная услуга/комплекс; неизвестная услуга или неизвестная общая длительность → Relay |
| Relay | Заявка сотруднику без подтверждения визита; также при ошибке календаря, отсутствии слотов, неизвестной услуге/комплексе и просьбах о переносе/отмене |
| Результат разговора | Не более одной записи либо одной переданной Relay-заявки |
| Контакт | Любой валидный E.164 (+48 по умолчанию для локальных 9-значных номеров), можно другой вместо Caller ID, без OTP; список стран в конфиге || Звонки | Один одновременный AI-разговор на автосервис, начальный максимум 180 секунд |
| Данные обращения | Имя, контакт, марка/модель, проблема; пожелание времени, включая «любое» |
| SMS | Только одному назначенному сотруднику, не звонящему |
| Администратор | Пока владелец Gloso, защищённый HTTP API без панели |
| Оповещения эксплуатации | Telegram администратору, без содержимого обращений |
| Пилот | Ручная активация, 14 календарных дней в Europe/Warsaw, 40 минут AI |
| Учёт | `ceil(ai_seconds / 60)` на каждый фактический AI-разговор, включая прерванные/спам |

### Начальные параметры расписания

- Часовой пояс Europe/Warsaw, рабочие интервалы по дням и исключения на даты.
- Польские государственные праздники закрыты по умолчанию; дату можно открыть исключением, саму политику можно изменить.
- Минимальный срок до визита 60 минут, горизонт 14 дней (до конца местного дня включительно), шаг начала 30 минут (сетка от 00:00, настраиваемо), дополнительный буфер 0 минут (при ненулевом — только между визитами, не режет конец дня); тестовая длительность по умолчанию 60 минут.
- Время «любое» не разрешает backend выбрать слот без согласования конкретного визита.
- Во время активного пилота можно создать визит на дату после его окончания, если она входит в горизонт; окончание пилота не отменяет событие Calendar.

## Главное о надёжности

- Без проверенного допуска новую AI-сессию не запускать. Уже начатую не обрывать из-за конца пилота или минут; отдельный максимум 180 секунд сохраняется.
- При недоступном пилоте/проверке допуска — маршрут телефонии без AI. При занятом AI — сообщение о занятости без очереди. Поддержка маршрутов ещё требует проверки.
- Созданный визит не отменяется из-за ошибки SMS.
- SMS повторяются ограниченно только в памяти и только при доказанном временном отказе без принятия. Неизвестный результат не повторяется вслепую.
- Неизвестное создание Calendar сначала сверяется; новые бронирования этого автосервиса приостанавливаются. Новые обращения можно принимать через Relay, но не дублировать исходную неизвестную операцию.

## Категории хранимых данных

1. **Конфигурация** автосервиса и получателя — разрешена; не объявляется анонимной.
2. **Краткоживущее техническое состояние** — проектно до 7 дней, без содержимого обращений; может быть псевдонимизированным.
3. **Зашифрованный аудит** — до 30 дней от окончания разговора, часовой интервал, списанные целые минуты, результат «запись создана» / «Relay передан» / «ошибка» либо отсутствие результата.

Имена/телефоны звонящих, автомобиль, проблема, время визита, заявки и SMS не сохраняются в БД, логах или долговечных очередях. В памяти обрабатываются только на время операции/ограниченных повторов. Backend не получает и не архивирует аудио/транскрипции. Источник истины о визите — календарь автосервиса; архива Relay у Gloso нет.

Часовая точность, шифрование и HMAC не гарантируют анонимность. Корреляция с внешними данными, техническими связями и конфигурацией должна учитываться отдельно.

## Что отложено

Переносы, отмены, OTP, параллельные визиты/разговоры сверх текущих ограничений, клиентские аккаунты/панель/OAuth, платные периоды, платежи, продление пилота/добавление минут, клиентские SMS.

Сохраняем точки расширения, но не реализуем перечисленное заранее. Для будущих переносов/отмен ранее выбраны работа в том числе с ручными визитами и SMS-код на телефон из записи; перед внедрением нужны отдельные спецификации и юридическое согласование.

## Стек и готовность

Node.js + TypeScript + Express, Zod, PostgreSQL + Drizzle. Размещение: Northflank + Neon в ЕЭЗ. Внешние сервисы: Twilio (Programmable Voice и Programmable Messaging), ElevenLabs, Google Calendar, Telegram для эксплуатации.

Начально 3–5 автосервисов, не жёсткий предел. Выбран модульный монолит с адаптерами; состояние проектируется с учётом нескольких экземпляров приложения. Есть тестовый Calendar и агент ElevenLabs; Twilio пока не подтверждён. Реализация сначала локальная с mock-адаптерами, затем реальные интеграции и сквозная проверка перед пилотом. Допуск до AI должен выполняться на маршруте Twilio; нативная интеграция ElevenLabs с Twilio, обходящая backend, не допускается к пилоту.
